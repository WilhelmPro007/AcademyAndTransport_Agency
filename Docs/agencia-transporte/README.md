## Punto de partida

El servicio puede combinar personal en China para buscar y verificar productos, una ruta de transporte internacional —incluyendo DHL cuando convenga— y un buzón en Estados Unidos como posible punto de recepción o consolidación.

## Siguiente decisión

Definir si el MVP será búsqueda por encargo, transporte de paquetes, o ambos; luego establecer una fórmula de cotización transparente.
