# Agencia de transporte — identidad gráfica

1. ¿La marca debe comunicar principalmente logística internacional, compra segura, conexión China-Nicaragua o ahorro?
2. ¿Debe ser corporativa/técnica, cercana para emprendedores o premium para importadores?
3. ¿Qué atributos debe transmitir: seguridad, transparencia, velocidad, respaldo, orden o capacidad?
4. ¿Se prefieren símbolos de ruta, puente, caja, comercio, conexión entre países o una solución abstracta?
5. ¿Qué colores, símbolos o referencias deben evitarse para no parecer una paquetería genérica?
6. ¿Qué nombres existen o están en consideración? ¿Están disponibles dominios y usuarios de redes?
7. **MVP:** ¿Dónde se usará primero la identidad: WhatsApp, Facebook, Instagram, web, cotizaciones, documentos, uniformes o empaques?
8. ¿Se necesitan versiones para fondo claro/oscuro, favicon, foto de perfil, sello y tamaños pequeños?
9. ¿Quién aprobará la identidad, qué presupuesto hay y cuál es la fecha límite?
10. Compartir 3 referencias visuales que gustan y 3 que no gustan, explicando por qué.
