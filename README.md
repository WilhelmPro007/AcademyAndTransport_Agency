# Academy & Transport Agency

Repositorio de documentación y futura lógica de negocio para dos servicios relacionados con China:

1. **Academia de chino en línea** — clases impartidas inicialmente por un docente con amplia experiencia.
2. **Agencia de búsqueda y envíos desde China** — búsqueda de productos, compra asistida, consolidación y transporte.
